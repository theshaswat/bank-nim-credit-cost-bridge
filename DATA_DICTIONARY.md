# Data Dictionary

## `data/final/verified_inputs.csv`

| Column | Type | Description |
|---|---|---|
| `bank` | string | Bank name as reported in its own filing |
| `basis` | string | `standalone` or `consolidated` — see note below on ICICI/Axis/HDFC/Kotak basis |
| `quarter` | string | `Q1 FY26` or `Q1 FY27` (quarter ended 30-Jun) |
| `interest_income` | float, ₹ Crore | Interest earned/income for the quarter — populated only where the bank discloses it as a separate line (Axis, ICICI) |
| `interest_expended` | float, ₹ Crore | Interest expended for the quarter — same availability as above |
| `nii_reported` | float, ₹ Crore | Net interest income as reported by the bank — populated only where the bank states NII directly as a line item (Axis, ICICI) |
| `pat` | float, ₹ Crore | Profit after tax for the quarter, all 4 banks |
| `avg_deposits` | float, ₹ Crore | Average deposits for the quarter, where disclosed (HDFC only) |
| `avg_advances` | float, ₹ Crore | Average advances for the quarter, where disclosed (HDFC, Kotak) |
| `nim_pct` | float, % | Reported headline net interest margin, where disclosed (HDFC, Kotak, and Axis Q1FY27 only) |
| `gnpa_pct` | float, % | Reported headline gross NPA ratio, where disclosed (HDFC, Kotak) |
| `credit_cost_pct` | float, % | Reported headline credit cost ratio, where disclosed (Kotak only) |
| `source_page_note` | string | Exact filing and page(s) this row's figures came from |

Blank cells throughout this file are deliberate — a bank not disclosing a
figure in a verifiable, page-cited form means that cell stays empty rather
than being filled from an unverifiable secondary source.

**Basis note:** all four banks are compared on standalone results this
quarter for Axis/HDFC/Kotak, and consolidated for ICICI — the basis each
bank's own primary results table presents at the quarter level. This is
stated per-row in the `basis` column rather than silently normalized.

## `data/final/margin_bridge.csv`

Output of `src/nim_bridge.py::build_bridge()`. One row per bank, comparing
Q1 FY27 to Q1 FY26:

| Column | Type | Description |
|---|---|---|
| `bank` | string | Bank name |
| `nii_growth_yoy_pct` | float or blank | `(NII_Q1FY27 / NII_Q1FY26 − 1) × 100` — only where both quarters report NII |
| `advances_growth_yoy_pct` | float or blank | Same formula, average advances |
| `pat_growth_yoy_pct` | float | Same formula, PAT — computed for all 4 banks |
| `nim_change_bps` | float or blank | `(NIM_Q1FY27 − NIM_Q1FY26) × 100`, in basis points |
| `gnpa_change_bps` | float or blank | Same formula, GNPA% |
| `credit_cost_change_bps` | float or blank | Same formula, credit cost% |
| `pat_q1fy27_cr` / `pat_q1fy26_cr` | float, ₹ Crore | Raw PAT figures behind the growth % |

## `data/processed/reconciliation_log.md`

Auto-generated by `src/nim_bridge.py::reconcile_nii()`. Runs
`indfin.reconcile.nii.check_nii()` — `interest_income − interest_expended =
nii_reported`, within a ₹5.00 Crore tolerance — for every bank-quarter where
all three figures exist (Axis and ICICI, both quarters). All 4 checks pass
with diff = 0.00 in every case.

## `data/raw/source_manifest.md`

One row per source PDF: bank, period, exact download URL, retrieval
timestamp, and SHA-256 hash, plus notes on each filing's layout and any
extraction caveats (e.g. the HDFC yield/cost-of-funds chart's label
ambiguity, or the Kotak Q1FY26 file corruption).
